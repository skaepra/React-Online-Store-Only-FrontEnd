# React + Vite
# React Online Store

A modern e-commerce web application built with React, TypeScript, Vite and Tailwind.

---

## Features

- User Authentication
- Product Categories
- Product Search
- Product Details
- Shopping Cart
- Wishlist
- Responsive Design
- Mock REST API using json-server

---

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind
- Zustand
- React Router
- Axios
- json-server

---

## Installation

Clone the repository

```bash
git clone https://github.com/YourUsername/React-Online-Store.git
```

Move into the project

```bash
cd React-Online-Store
```

Install dependencies

```bash
npm install
```

Start the mock API

```bash
npm run server
```

Run the development server

```bash
npm run dev
```
